# EFFEW

Sito one page di EFFEW S.R.L.S. (ritiro, riparazione e consegna di pedane a Pisa).

- `index.html`: pagina completa, nessuna dipendenza oltre a Google Fonts.
- `assets/`: video hero e foto, generati con Picsart e ottimizzati per il web.

Per cambiare l'indirizzo email dei pulsanti modifica la variabile `EMAIL` nello script in fondo a `index.html`
(e rimuovi l'etichetta `.segnaposto` nella sezione contatti).
